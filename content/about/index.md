我是沈显鹏，在立陶宛维尔纽斯。

做软件十六年，从测试、测试开发、开发一路做到 DevOps。带过 QA 团队，写过自动化，维护过多条产品线的 Jenkins 流水线，做过 Artifactory、容器化、Ansible、代码覆盖率和软件供应链安全（SLSA、SBOM），也在 AIX 这样的老平台上踩过坑。博客从 2017 年写到现在的 250 多篇文章，大多是这些活的记录。

这些活里长出了几个开源工具：[cpp-linter](https://github.com/cpp-linter)，每个 PR 上跑 clang-format 和 clang-tidy，Apache、Samsung、Qualcomm、Bloomberg 等 1000 多个公开仓库的 CI 在用；[commit-check](https://github.com/commit-check/commit-check)，一份策略统一校验提交信息、分支名和 AI 署名；[Conventional Branch](https://conventionalbranch.org)，分支命名规范；[Open Delivery Spec](https://github.com/open-delivery-spec)，把构建、测试、评审、部署的过程变成机器可校验的证据；还有 jenkinsci 组织下的两个项目，[explain-error-plugin](https://github.com/jenkinsci/explain-error-plugin)（用 AI 解释构建失败）和 [jenkinsfilelint](https://github.com/jenkinsci/jenkinsfilelint)（不用 Jenkins 服务器也能校验 Jenkinsfile）。

产品有三个：[keelinfra](https://keelinfra.io)，生产可用的自托管 Keycloak；[keelapps](https://keelapps.app)，Jira 与 Confluence Cloud 的管理工具；[Keelhaven](https://keelhaven.app)，把 Mac 备份到你自己的存储。全部列在[作品](/zh-cn/portfolio/)页。

Jenkins GitHub 组织成员，EuroPython 2025 议题评审，2026 年入选 Anthropic Open Source Developer Program。
